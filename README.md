Entry for the [make.fun bounty](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610): one original line, at most 200 characters, roasting a gadget I use every day.

## The line

> My left AirPod dies at 80% while the right one carries the whole phone call like a single parent.

**97 characters.**

## How it works

`main.ts` holds the line, checks it (1–200 characters, one line, not only whitespace), writes exactly that line to `MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) with no trailing newline, then reads the file back and confirms it matches byte for byte. Two runs produce identical bytes.
